# DArk : Echo Sector (Hacker Mode)

# HACKER MODE

## Features Implemented

* Currency collection system from defeated enemies
* Shop system for purchasing upgrades
* Health upgrade purchase
* Speed Boost powerup
* Locked doors until enemies are cleared
* Multiple rooms with increasing difficulty
* Enhanced enemy AI states (Idle, Alert, Chase, Death)
* Score and timer system
* Win and Game Over screens
* Pause and Restart functionality

## Technologies Used

* HTML
* CSS
* JavaScript
* HTML Canvas API

## Controls

* WASD - Move
* Mouse - Aim
* Left Click - Shoot
* P - Pause/Resume
* R - Restart
* B - Open/Close Shop
